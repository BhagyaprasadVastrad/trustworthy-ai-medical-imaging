# External data layout

This repository does not redistribute the RSNA Pneumonia Detection Challenge data.

Place the separately obtained RSNA data here:

```
data/rsna_pneumonia/
├── raw/images/
└── annotations/pneumonia-challenge-annotations-original_2018.json
```

PneumoniaMNIST is downloaded automatically through MedMNIST during baseline training.

The RSNA dataset should be obtained from the official challenge resources and used according to its terms.
